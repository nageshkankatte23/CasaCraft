# 🏠 CasaCraft – Interior Design Website

CasaCraft is a modern, responsive interior design website developed using HTML5, CSS3, and JavaScript. It showcases creative interior designs for living rooms, bedrooms, kitchens, and offices.

## ✨ Features
- Responsive and user-friendly design
- Home, About, Services, Projects, and Contact sections
- Interior design gallery with category filters
- Dark mode toggle
- Favorite projects functionality
- Interactive contact form
- Modern navigation bar and footer

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 🚀 How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser or use Live Server.

## 🎯 Project Objective
To create an attractive and interactive website that showcases interior design ideas and provides users with an engaging browsing experience.
